# مصفوفة التحقق من المرحلة الثانية: وكلاء الذكاء الاصطناعي وبوابة MCP (Agents & MCP Architecture)

- **رقم المرحلة:** Phase 02
- **الاسم المختصر:** `agents-mcp`
- **نطاق المرحلة:** تهيئة وتفعيل منظومة وكلاء الذكاء الاصطناعي (Custom Agents)، وتفعيل صمامات الأمان والموافقة البشرية (Human-in-the-Loop / Tool Approval)، وربط بوابة MCP المركزية (`mcp.alazab.com`) بخوادم أعمال المنظومة (دفترة، أوبر فيكس، ERPNext، واتساب، ماجيك بلان، وسوبابيز)، وربط الأدوات بقوالب النماذج التخصصية (Model Specs).
- **الملفات المعنية:**
  - `librechat.alazab.yaml`
  - `librechat.yaml`
  - `.env.alazab.example`
  - `packages/data-provider/src/config.ts`
